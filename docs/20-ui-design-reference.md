# UI Design Reference

The user's visual direction is a WhatsApp-style messaging interface with both light and dark theme support.

Default app theme:

```text
Light theme
```

## Reference Direction

- Light and dark themes both exist.
- Light theme is the default.
- Dark theme uses near-black chat surfaces.
- Bright green primary action accent in both themes.
- Rounded search bar and message input.
- Circular avatars.
- Dense chat/call lists with strong hierarchy.
- Bottom navigation with icon-first tabs.
- Chat detail with dark doodle-like background feel.
- Outgoing bubbles use green.
- Incoming bubbles use dark gray.
- Call/action floating buttons use green.

## ContactMe Interpretation

Use this direction for future ContactMe UI polish, while keeping ContactMe's own branding and defaulting to light mode.

Avoid making the app a direct clone. The goal is:

```text
WhatsApp-like familiarity
+ ContactMe green accent, spacing, and identity
+ clean Android Material implementation
+ light mode by default
+ dark mode available
```
