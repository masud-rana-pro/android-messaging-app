# Chat List Polish

Home Chats now shows formatted conversation timestamps and keeps row text compact.

## Added

- Today: `h:mm AM/PM`
- Yesterday: `Yesterday`
- Older: `M/d/yy`
- Conversation title and preview are single-line with ellipsis.

## Verify

1. Send a message.
2. Go back to Home.
3. Confirm the conversation row shows the last message and time.
4. Confirm long messages stay on one row with ellipsis.
