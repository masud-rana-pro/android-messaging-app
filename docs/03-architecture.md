# Architecture

## Starter Stack

- Android: Kotlin, Jetpack Compose, Hilt, Coroutines, Flow
- Auth: Firebase Auth
- Chat: Firestore listeners
- Presence: Firebase Realtime Database
- Media: Firebase Storage
- Notifications: FCM and Cloud Functions
- Calls: ZegoCloud SDK

## Scale Path

Keep the project ready for future custom API, realtime server, workers, search, and admin dashboard services.

## Android System Components

See `09-android-system-components.md` for the planned use of Activity, FileProvider, BroadcastReceiver, Foreground Service, FirebaseMessagingService, WorkManager, Room, permissions, and notification channels.
